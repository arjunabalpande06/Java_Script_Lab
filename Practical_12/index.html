Practical 12: Interactive Real-Time Weather Dashboard

Technologies: HTML5 • CSS3 • JavaScript (ES6) • jQuery 3.7.1 • AJAX • LocalStorage

Weather API Configuration

Select your preferred weather data provider. By default, Open-Meteo works out-of-the-box without requiring an API key. You can also configure your personal OpenWeatherMap API key.

Keys can be generated for free at openweathermap.org/api. The key is securely stored in your browser's localStorage.
Browser Storage Integration:

Your API provider choice, custom key, last searched city, temperature units, and history are automatically preserved across sessions using the HTML5 localStorage API.
