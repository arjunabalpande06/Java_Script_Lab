# JavaScript Lab

A collection of JavaScript laboratory practicals demonstrating core JavaScript concepts, programming techniques, DOM manipulation, form validation, browser storage, and asynchronous data handling.

## 📌 About the Repository

This repository contains 10 JavaScript practicals developed as part of the JavaScript Laboratory coursework. Each practical focuses on implementing important JavaScript concepts through simple, interactive, and real-world programming examples.

The objective is to develop practical knowledge of JavaScript and understand how it is used to create dynamic and interactive web applications.

## 🎯 Objectives

- Understand JavaScript fundamentals and syntax.
- Explore variables, data types, operators, and functions.
- Implement conditional statements and loops.
- Work with arrays, objects, and string methods.
- Understand DOM manipulation and event handling.
- Perform client-side form validation.
- Store data using Local Storage and Session Storage.
- Fetch and display JSON data dynamically.
- Develop interactive web-based applications.

## 🛠️ Technologies Used

- **HTML5** – Structure of web pages.
- **CSS3** – Styling and page design.
- **JavaScript (ES6+)** – Programming and interactivity.
- **jQuery** – Simplified DOM manipulation and JSON handling.
- **JSON** – Data representation and exchange.

## 📂 Practical List

| Practical | Topic | Implementation |

## 🚀 Getting Started

Follow these steps to run the practicals on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/arjunabalpande06/Java_Script_Lab.git
```

### 2. Navigate to the Project Folder

```bash
cd Java_Script_Lab
```

### 3. Open a Practical

Navigate to the required practical folder.

```bash
cd Practical_1
```

### 4. Run the Program

- Open the HTML file in your preferred web browser.
- Alternatively, open the project in Visual Studio Code.
- Use the browser's Developer Tools (F12) to view console output and debug JavaScript code.

**Note:** For practicals involving Fetch API or local data files, use a local development server such as VS Code Live Server.

## 💡 Learning Outcomes

After completing these practicals, students will be able to:

- Write and execute JavaScript programs.
- Apply ES6+ features in practical applications.
- Develop interactive web pages.
- Manipulate HTML elements using the DOM.
- Validate user input using JavaScript.
- Work with browser storage mechanisms.
- Retrieve and process JSON data.
- Understand basic asynchronous JavaScript operations.
