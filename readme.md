# JavaScript Lab Practicals

A collection of JavaScript laboratory practicals demonstrating core JavaScript concepts, modern ES6+ features, DOM manipulation, event handling, form validation, browser storage, asynchronous programming, AJAX integration, and interactive web application development.

## 📌 About the Repository

This repository contains **12 JavaScript practicals** developed as part of the JavaScript Laboratory coursework.

Each practical focuses on implementing important JavaScript concepts through simple, interactive, and real-world programming examples.

The objective is to develop practical knowledge of JavaScript, jQuery, and modern web technologies used to create dynamic and interactive web applications.

## 🎯 Objectives

- Understand JavaScript fundamentals and syntax.
- Explore variables, data types, operators, and functions.
- Implement conditional statements and loops.
- Work with arrays, objects, and string methods.
- Understand DOM manipulation and event handling.
- Perform client-side form validation.
- Store data using Local Storage and Session Storage.
- Understand JSON and AJAX communication.
- Work with JavaScript timers and asynchronous operations.
- Implement ES6 modules using import and export.
- Learn jQuery for simplified DOM manipulation and event handling.
- Develop interactive and responsive web applications.

## 🛠️ Technologies Used

- **HTML5** – Structure of web pages.
- **CSS3** – Styling and responsive page design.
- **JavaScript (ES6+)** – Programming and interactivity.
- **jQuery** – Simplified DOM manipulation and event handling.
- **JSON** – Data representation and exchange.
- **AJAX** – Asynchronous data retrieval.
- **Web APIs** – Integration with external services.
- **Local Storage** – Client-side data persistence.

## 🚀 Getting Started

Follow these steps to run the practicals on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/arjunabalpande06/Java_Script_Lab.git
```

### 2. Navigate to the Project Folder

```bash
cd Java_Script_Lab
```

### 3. Open a Practical

Navigate to the required practical folder.

```bash
cd Practical_1
```

### 4. Run the Program

- Open the project in Visual Studio Code.
- Navigate to the required practical folder.
- Open the HTML file.
- Use the VS Code Live Server extension to run the application.
- Use browser Developer Tools (F12) to view console output and debug JavaScript code.

**Important:** Live Server is recommended for practicals involving ES6 modules, AJAX, Fetch API, and external API integration.

### API Configuration

Practical 12 uses a weather API to retrieve real-time weather information.

- Obtain an API key from the weather service provider.
- Configure the API key as required by the application.
- Ensure internet connectivity for AJAX requests.
